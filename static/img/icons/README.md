# Resource button icons

These marks identify the corresponding external platforms. Artwork is stored
locally so the homepage does not depend on third-party image requests.

| File | Source |
| --- | --- |
| `arxiv.svg` | [arXiv small logomark](https://info.arxiv.org/assets/arxiv-logomark-small.svg), [brand page](https://info.arxiv.org/brand/logos.html) |
| `github.svg` | [GitHub Mark from Primer Octicons](https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-16.svg) |
| `huggingface.svg` | [Hugging Face logo](https://huggingface.co/front/assets/huggingface_logo-noborder.svg), [brand assets](https://huggingface.co/brand) |
| `modelscope.svg` | [ModelScope simple logo](https://modelscope.cn/models/modelscope/logos/resolve/master/svg/modelscope-simple.svg) |

The Hugging Face SVG has an explicit viewBox matching its original 95 × 88
canvas for reliable scaling. The artwork is otherwise unchanged.
